🌟 Características

🔒

Sistema de Seguridad

Cada paquete es analizado automáticamente. Detecta código malicioso, bloquea acciones peligrosas y asigna una puntuación de confianza.

💰

100% Gratis

Todas las apps y ACTs son completamente gratuitas. Sin anuncios, sin pagos ocultos, sin trucos.

🚀

Instalación Instantánea

Instala apps y ACTs con un clic. El sistema verifica permisos y te muestra exactamente qué hará cada paquete.

📦

Open Source

Todo el código es abierto. Puedes revisar, modificar y contribuir al catálogo en GitHub.

🔄

Actualizaciones

El catálogo se actualiza desde GitHub Pages en tiempo real. Siempre tendrás las últimas versiones.

🤝

Community Driven

Cualquiera puede enviar sus creaciones. El sistema revisa automáticamente la seguridad antes de aprobar.

📡 API Documentation

Conecta tu sistema XP7 a la store usando esta API REST 

// Endpoint principal (ejemplo)
GET https://[tu-usuario].github.io/xp7-store/store.json

// Respuesta
{
  "version": "2.0.0",
  "lastUpdate": "2025-01-22",
  "apps": [...],
  "acts": [...]
}

Estructura de Apps (PAK)

{
  "id": "mi-app",
  "type": "application",
  "name": "Mi App",
  "version": "1.0.0",
  "description": "Descripción corta",
  "author": "Tu nombre",
  "icon": "🚀",
  "category": "Utilidades",
  "width": 600,
  "height": 400,
  "content": "<html>...</html>"
}

Estructura de ACTs

{
  "id": "mi-act",
  "type": "update",
  "name": "Mi ACT",
  "version": "1.0.0",
  "description": "Descripción corta",
  "author": "Tu nombre",
  "icon": "🔄",
  "actions": [
    {
      "type": "showNotification",
      "title": "Título",
      "message": "Mensaje"
    },
    {
      "type": "injectCSS",
      "content": "body { ... }"
    }
  ]
}
